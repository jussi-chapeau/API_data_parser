# Gotchas

Hard-won lessons that cost real time to discover. Read this before touching an area it covers —
these exist so nobody (human or agent) re-derives them the hard way a second time.

One entry per lesson, in this shape:

**One-line name of the gotcha.** What looked wrong / what the naive fix would be, why that naive fix
is actually wrong, what the correct approach is, and where it's implemented (file/function). Flag
anything that's environment- or context-tunable rather than a fixed universal constant, and mark
still-open follow-ups with ⏳.
