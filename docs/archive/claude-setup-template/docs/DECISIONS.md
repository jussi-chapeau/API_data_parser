# Decisions

Chronological log of architecture/design decisions and why — newest entry last. Not a duplicate of
`git log`: this is for decisions where the *reasoning* matters more than the diff, especially ones
that reject a plausible alternative for a specific reason (so nobody re-proposes it without knowing
why it was already rejected).

One entry per decision:

## YYYY-MM-DD — [decision title]
What was decided, what the rejected alternative(s) were, and why this one won. Keep it to a few
sentences — this is a log, not a design doc.
